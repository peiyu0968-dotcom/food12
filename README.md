# food12：StyleMate AI（簡化版）

StyleMate AI 是一支跑在你電腦上的 Discord bot。**簡化版只做三件事：**

1. **AI 辨識衣服照片並加入衣櫃**：傳一張衣服照片，AI 辨識種類、顏色、材質、風格，你選要加入哪幾件。
2. **個人衣櫃管理**：查看、修改、刪除（可復原）、保留修改歷史。
3. **AI 推薦穿搭**：告訴它場合，它只從你衣櫃裡「真正存在」的衣服配一套，並說明理由。

資料用 Excel 存放，每位使用者一個獨立資料夾，彼此隔離。

> 專案原本是「食物照片記錄 agent」，因老師規定不能做食物主題而改版。GitHub 儲存庫名稱 `food12` 暫時不改名，程式套件名稱是 `stylemate_ai`。

## 啟動

```powershell
uv sync                 # 第一次，或套件有變動時
uv run stylemate        # 啟動 agent（Ctrl+C 結束）
```

等價的寫法：`uv run python -m stylemate_ai`

第一次使用前：

1. 照 `docs/discord-server-setup.md` 建好 Server 和頻道。
2. 照 `docs/discord-bot-setup.md` 建好 bot、打開 **Message Content Intent**，並勾 **View Channels、Send Messages、Read Message History、Add Reactions、Attach Files** 五個權限。
3. 把真的 `DISCORD_TOKEN` 和 `CHANNEL_ID` 填進專案根目錄的 `.env`（**不要貼進對話、不要 commit**）。

`.env` 四個項目：

| 項目 | 意思 |
|---|---|
| `DISCORD_TOKEN` | bot 的登入密碼，絕不公開 |
| `CHANNEL_ID` | 只聽這一個頻道 |
| `CLAUDE_MODEL` | 給 `claude -p` 用的模型，例如 `haiku`、`sonnet` |
| `DATA_DIR` | 放所有人的資料的資料夾（預設 `./data`） |

## 怎麼用

在指定頻道：

| 要做的事 | 怎麼做 |
|---|---|
| 加衣服進衣櫃 | 直接傳衣服照片 → ⏳ → bot 列出每一件 → 按按鈕或回覆「全部」「1,3」「都不要」（10 分鐘內有效，沒選就什麼都不會儲存） |
| 看衣櫃 | `!衣櫃`、`!衣櫃 外套`、`!衣櫃 顏色:黑 風格:簡約`、`!衣櫃 2` |
| 看單件 | `!查看 <ID或名稱>` |
| 修改 | `!修改 <ID> 材質=亞麻 保暖=2 原因:洗過縮水` |
| 刪除／復原／只刪照片 | `!刪除 <ID>`（要確認、可復原）、`!復原 <ID>`、`!刪圖 <ID>` |
| **AI 推薦穿搭** | `!推薦 明天面試`、`!推薦 週末去爬山，可能下雨`；不滿意按「再來一套」或輸入 `!再來一套` |
| 說明 | `!說明` |
| 刪除全部資料 | `!刪除全部資料`（按鈕＋打出「確認刪除全部」兩道確認） |

- 第一次使用會先出現**隱私說明**，按「我同意」或回覆「我同意」才開始。
- **公開提醒**：`!衣櫃`、`!查看`、`!推薦` 會顯示你的衣櫃內容，在公開頻道會先提醒「所有成員都看得到」，你確認後 30 分鐘內可連續公開顯示（每位使用者各自計時），每則上方標示「🔓 公開顯示中」；`!結束公開` 可提前結束。
- **每個按鈕都有打字替代**：回覆 bot 的那則訊息即可（「全部」、「確認」、「確認公開」、「我同意」、「再來一套」…）。

### AI 推薦穿搭怎麼運作

1. 你說場合與需求（天氣、溫度直接寫在句子裡就行，不用另外查天氣）。
2. 程式只取**你自己**衣櫃裡狀態正常的衣服，把「編號、名稱、種類、顏色、材質、風格、保暖與正式程度…」交給 `claude -p`（不給任何工具、不給任何檔案）。
3. AI 回一套：衣服編號清單＋理由＋缺少什麼。**程式逐一驗證**：每個編號都必須在剛交給它的清單裡、屬於你、沒被刪除；一套要有洋裝，或上衣加下著；跟上一套重複也不行。不合格就重試一次，還是不合格就回「暫時沒辦法處理」，**不會顯示任何一件不存在的衣服**。
4. 衣櫃缺東西時，會用現有的湊最接近的，並建議「可以添購哪一類」（只說類型，沒有商品、網址或價格）。

## 資料放哪裡

```
DATA_DIR/
├─ agent.log                      ← 運作紀錄（不記衣服內容）
└─ users/<Discord 使用者 ID>/       ← 每人一個，彼此隔離
   ├─ wardrobe.xlsx               ← 衣櫃／穿搭紀錄／修改歷史／個人設定 四張工作表
   └─ photos/
```

## 隱私與資料不進 git

- `.env`、`DATA_DIR` 底下的照片、Excel、個人設定**都不會**被 commit，更不會上傳到公開的 GitHub（`.gitignore` 已擋住 `.env`、`data/`、`*.xlsx`、`photos/`、`*.log` 等）。
- 每位使用者只能碰自己的資料夾；按鈕與打字確認只認發起者本人。
- 推薦穿搭時，只有發起者自己的衣服資料會交給 AI，別人的衣櫃不會出現在任何提示裡。

## 不干擾老師的評分流程

bot 對 `ready` 和 `/done` 完全不回應、不加反應、不處理，也不會在頻道主動發出這兩個字或啟動訊息。

## 八段防護在哪裡

每一段都用下面這種註解框起來，**一開始全部開啟**。想關掉某一段，把「開始」到「結束」之間整段註解掉即可（程式仍能執行；框外那幾行就是「沒有防護」時的預設行為）。

| 防護 | 檔案 | 行數（大約） | 做什麼 |
|---|---|---|---|
| 1：`claude -p` 的檔案範圍隔離 | `src/stylemate_ai/claude_client.py` | 87–99 | 看照片時只給讀檔工具、鎖在只有那一張照片的暫存資料夾；純文字任務（推薦）一個工具都不給；都讀不到別人的資料 |
| 2：使用者的字與衣櫃資料只當資料 | `src/stylemate_ai/claude_client.py` | 101–110 | 只放進標準輸入的「資料區塊」，不進指令列；拿掉偽造標籤、限制長度；規則放系統提示 |
| 3：衣服名稱當檔名前先清洗 | `src/stylemate_ai/photos.py` | 63–67 | 清掉 `/ \ ..` 冒號等字，並確認檔案落在該使用者的照片資料夾內 |
| 4：Excel 文字不被當公式 | `src/stylemate_ai/excel_store.py` | 71–77 | 以 `= + - @` 開頭的文字強制設為文字，並加單引號 |
| 5：額度、頻率與檔案保護 | `src/stylemate_ai/limits.py` | 66–91 | 照片每人每分鐘 3 張、AI 請求每分鐘 5 次、同時 3 件、圖片 10 MB 與格式限制 |
| 6：使用者隔離與權限檢查 | `src/stylemate_ai/access.py` | 26–47 | 資料夾只能是數字 ID 且在 `users/` 底下；只認發起者本人 |
| 7：Discord 輸出不觸發 @ 提及 | `src/stylemate_ai/replies.py` | 18–23 | 回覆一律不通知任何人 |
| 8：衣服 ID 必須存在且屬於提問者 | `src/stylemate_ai/wardrobe.py` | 48–53 | 你打的 ID，和 **AI 推薦回傳的 ID**，都要存在、屬於你、沒被刪除 |

註解格式：

```python
# ==== 防護 1：claude -p 的檔案範圍隔離　開始 ====
...
# ==== 防護 1 結束 ====
```

我用測試驗證過：把任何一段整段註解掉，程式仍能載入，而且只有對應那一段的測試會失敗。

## 測試

```powershell

```
