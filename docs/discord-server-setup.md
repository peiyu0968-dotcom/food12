# Discord Server 設定步驟

> 這份文件帶你做三件事：
> 1. 建立一個你自己的 Discord Server（伺服器，就是一個專屬的聊天空間）
> 2. 建立一個給 agent 用的頻道，並拿到它的 `CHANNEL_ID`（頻道的編號）
> 3. 產生邀請連結，讓同組同學加入
>
> 前提：你已經有 Discord 帳號。電腦是 **Windows**。
> 做完這份，再去做 `docs/discord-bot-setup.md`（建立 bot 並邀進這個 Server）。
>
> **畫面可能和文件有一點不同**：Discord 會改版，也可能是中文或英文介面。我在中文後面用括號附上英文，找不到時請對照另一個語言。

---

## 開始之前

用 **Discord 電腦版 App** 或 **網頁版**（網址 `https://discord.com/app`）都可以，下面的步驟一樣。請先登入。

---

## 第一部分：建立你自己的 Server

1. 看畫面**最左邊**那一條直的圖示列。往下找，會看到一個**綠色的加號 `+`**，旁邊提示是「新增伺服器」（Add a Server）。**用滑鼠左鍵點它**。
2. 跳出視窗，點最上面的 **「親自創建」**（Create My Own）。
3. 下一個畫面問你這個 Server 是給誰用的，點 **「供我和我的朋友使用」**（For me and my friends）。
4. 下一個畫面是自訂伺服器：
   - **伺服器名稱**（Server Name）欄位：打你喜歡的名字，例如 `食物記錄測試`。
   - 圖示可以不用管。
   - 點右下角的 **「創建」**（Create）。
5. 你會被帶進新的 Server。左邊會多一個圓形圖示，就是它。

> 你就是這個 Server 的擁有者，可以決定誰能進來、誰能做什麼。

---

## 第二部分：建立給 agent 用的頻道

新 Server 會自動有一個 `#一般`（`#general`）文字頻道。我們另外開一個專門的，才不會跟閒聊混在一起。

1. 看畫面**左邊第二欄**（Server 的內容）。找到分類名稱 **「文字頻道」**（Text Channels）。
2. 把滑鼠移到「文字頻道」這幾個字上，右邊會出現一個 **`+`**。**點它**。
3. 跳出「建立頻道」視窗：
   - 頻道類型選 **「文字」**（Text）。
   - **頻道名稱**（Channel Name）打 `food-log`（Discord 會自動把大寫變小寫、空白變成連字號，沒關係）。
   - **「私人頻道」**（Private Channel）那個開關**先不要打開**。原因：打開後同學要另外授權才看得到，初學時容易卡住。測試順利後想限制人時再回來設定（見最後的「安全提醒」）。
4. 點右下角 **「建立頻道」**（Create Channel）。
5. 左邊的頻道清單裡就多出 `# food-log`。

---

## 第三部分：拿到 CHANNEL_ID

`CHANNEL_ID` 是這個頻道在 Discord 內部的一組數字編號（大約 18～19 位數）。agent 靠它知道「只聽這一個頻道」。

Discord 預設不會顯示這個編號，要先打開「開發者模式」。

### 3-1 打開開發者模式（只需做一次）

1. 看畫面**左下角**，你的頭像和名字旁邊有一個 **齒輪圖示**（使用者設定，User Settings）。**點它**。
2. 在左邊的選單往下捲，找到 **「進階」**（Advanced）。如果找不到，先看 **「App 設定」**（App Settings）區塊底下。**點「進階」**。
3. 在右邊找到 **「開發者模式」**（Developer Mode），把它的開關**打開**（變成綠色）。
4. 按右上角的 **`X`** 或鍵盤的 `Esc` 關掉設定。

### 3-2 複製頻道編號

1. 在左邊頻道清單，**用滑鼠右鍵**點 `# food-log`。
2. 跳出選單，滑到最下面，點 **「複製頻道 ID」**（Copy Channel ID）。
3. 現在這串數字已經在你的剪貼簿裡了。打開 **記事本**（Notepad），按 `Ctrl + V` 貼上，確認是一串很長的數字，例如 `123456789012345678`。先留著，等一下要放進 `.env`。

> 如果右鍵選單裡沒有「複製頻道 ID」，代表第 3-1 的開發者模式沒打開成功，請回去重做。

> `CHANNEL_ID` 不是密碼，貼給別人沒關係。但沒必要到處貼。

---

## 第四部分：產生邀請連結，讓同組同學加入

1. 在左邊頻道清單，**用滑鼠右鍵**點 `# food-log`，選 **「邀請其他人」**（Invite People）。
   - 從這個頻道發邀請，同學加入後一進來就會落在這個頻道，不會迷路。
2. 跳出視窗，裡面有一條連結，長得像 `https://discord.gg/xxxxxxx`。
3. 先別急著複製。**點視窗下方的「編輯邀請連結」**（Edit invite link，旁邊有個齒輪圖示）：
   - **「連結過期時間」**（Expire After）：選 **7 天**（測完就不能再用）。
   - **「使用次數上限」**（Max Number of Uses）：選一個稍大於同組人數的數字，例如同組 4 人就選 **5**（沒有太多額外名額）。
   - 其他選項保持預設。
4. 點 **「產生新連結」**（Generate a New Link）。
5. 點連結旁邊的 **「複製」**（Copy）按鈕。
6. 貼到你們組的群組（LINE、Messenger 等）給同學。

### 同學收到連結後要做的

1. 點連結，會打開 Discord（網頁或 App）。
2. 點 **「接受邀請」**（Accept Invite）。
3. 進來後，在左邊點 `# food-log` 就能看到頻道、傳照片。

---

## 完成檢查

- [ ] 左邊有你的 Server，裡面有 `# food-log`
- [ ] 你已經把 `CHANNEL_ID` 貼在記事本裡看過（一串長數字）
- [ ] 同學用邀請連結加入後，看得到 `# food-log`

下一步：照 `docs/discord-bot-setup.md` 建立 bot 並邀請進來。

---

## 安全提醒

- **每個進頻道的人，都可以讓你的 agent 處理照片，也就是花掉你自己的 Claude 額度**（詳見 `docs/architecture.md` 第 13 節）。所以只邀請信任的同學，邀請連結設期限和次數上限，用完就讓它過期。
- 要停用連結：在 Server 名稱旁點一下 → **「伺服器設定」**（Server Settings）→ **「邀請」**（Invites）→ 在那條連結右邊點 `X`。
- 要限制頻道只讓特定人看到：右鍵點 `# food-log` → **「編輯頻道」**（Edit Channel）→ **「權限」**（Permissions）→ 打開「私人頻道」，再把允許的人或 bot 加進去。這一步等測試順利後再做。
