# 需求說明：StyleMate AI 智慧穿搭與衣櫃管理助理

> 這個專案原本是「食物照片記錄 agent」。老師規定不能做食物主題，所以改成 StyleMate AI。
> 食物版的程式與 git 歷史會保留；GitHub 遠端儲存庫名稱 `food12` **暫時不改名**，程式內部套件名稱改為 `stylemate_ai`。
> 下面的內容來自 18 題需求確認，以及「老師的評分 Agent 會進入我的 Server 觀察」這項後續修正。

> ## ⚠️ 目前範圍：簡化版（以這段為準）
> 只做**三個核心功能**：①AI 辨識衣服照片並加入衣櫃 ②個人衣櫃查看／修改／刪除（軟刪除可復原、保留修改歷史）③AI 依指定場合與衣櫃現有衣服推薦穿搭。
> **保留但預設關閉**（程式已寫好，不對使用者開放）：穿搭紀錄、衣服使用次數、統計、天氣、偏好設定。
> **停止開發**：天氣 API、自然語言聊天、斜線指令、私訊。下面各節中與這些有關的內容，是原本的完整規劃，目前不會實作。
> 隱私、使用者隔離、公開提醒、Excel 儲存、八段防護、不干擾 `ready`／`/done` 都維持不變。

## 這是什麼

一個在我自己電腦上執行的 Discord agent（一支會自己收訊息、自己做事、自己回覆的小程式）。只要它開著，我 Discord Server 裡指定頻道的人可以：

- 上傳衣服照片，讓 AI 辨識種類、顏色、材質與風格，並選擇要加入自己的電子衣櫃；
- 根據場合、天氣與個人偏好，從自己的衣櫃推薦完整穿搭；
- 記錄每天穿了什麼，統計衣櫃使用率與常穿風格；
- 修改、刪除、復原自己的衣服資料，並保留修改歷史；
- 用自然語言（日常口語）操作以上所有功能。

agent 關掉就不處理。

## 誰會用

我自己 Discord Server 裡、那個指定頻道的多位使用者，用手機或電腦都可以。**每個人的衣櫃是各自獨立的**，用 Discord 的使用者 ID 區分。

另外，**老師的評分 Agent 會進入我的 Server，觀察我操作自己的 Bot**。所以主要功能都必須能在指定的「公開頻道」完整展示。

## 三種互動方式（功能相同，使用者自己選）

| 方式 | 特色 |
|---|---|
| **公開頻道**（主要展示方式） | 在指定頻道直接傳照片、@bot 說話、打 `!` 開頭的文字指令。結果大家看得到 |
| **斜線指令** | 輸入 `/` 叫出的指令。預設只有自己看得到，也可以選擇公開 |
| **私訊** | 一對一私聊 bot，結果只有自己看得到 |

**所有按鈕都有「打字回覆」的替代方式**（例如按「全部加入」＝回覆「全部」）。原因是自動化的評分程式不一定能按按鈕或執行斜線指令，文字一定能用。

## 使用的流程（公開頻道能完整展示的八項功能）

1. **上傳與辨識**：有人在頻道傳衣服照片 → bot 在訊息上加 ⏳ → AI 辨識 → bot 公開回覆照片裡看到的每一件衣服（名稱、種類、顏色、風格、信心）和一句不看衣櫃的通用搭配提示。
2. **選擇並加入衣櫃**：使用者按按鈕或回覆「全部」「1,3」選要加入哪幾件；10 分鐘沒選就取消，什麼都不存。公開頻道只顯示「✅ 已加入 N 件」。
3. **查詢自己的衣櫃**：例如 `!衣櫃`、`!衣櫃 外套`，或 @bot「我有哪些外套」。
4. **AI 穿搭推薦與天氣分析**：例如 @bot「明天面試，幫我配一套」。bot 查天氣（或採用使用者說的天氣）、參考偏好，從**自己的衣櫃**推薦；預設一套，要再看才給下一套；衣櫃缺東西時建議可以買哪一類。
5. **每日穿搭紀錄**：按「今天穿這套」，或說「今天穿白襯衫加牛仔褲」；可補記過去、同一天可記多次。
6. **使用率與統計**：`!統計`，顯示最近 30 天（可改）的衣櫃使用率、最常穿、很久沒穿、常穿風格與顏色。
7. **修改、刪除、復原**：可以改衣服的欄位；刪除是軟刪除（可復原）；每次修改都寫進修改歷史。
8. **自然語言互動**：@bot 用口語說想做什麼，bot 聽懂後執行。

## 公開展示的提醒規則

公開頻道所有人都看得到，所以：

- **公開頻道本來就會顯示的**：使用者自己主動上傳的照片、辨識結果、一般搭配提示、「已加入 N 件」。
- **屬於個人資料的**（衣櫃清單、推薦穿搭、穿搭紀錄、統計、偏好、修改歷史）：在公開頻道顯示**之前**，bot 必須先清楚提醒「接下來的內容會被頻道所有成員看到」，使用者確認（按鈕或回覆「確認公開」）才顯示。確認後的 **30 分鐘內**可以連續公開展示，每則結果都標示「🔓 公開顯示中」；隨時可以回覆「結束公開」。
- 使用者不想公開，可以改用斜線指令（預設私下）或私訊。
- **不論哪種方式，使用者只能查詢、修改、刪除自己的資料**，不能存取別人的。

## 要記錄的內容

每位使用者一個獨立資料夾（用 Discord 使用者 ID 命名），放在 `DATA_DIR` 下，裡面有自己的衣服照片和一個 Excel 檔，Excel 有四張工作表：

- **衣櫃**（每件衣服一列，有唯一 ID）：名稱、種類、顏色、材質、風格、圖案、適合季節、保暖程度（1–5）、正式程度（1–5）、AI 信心、備註（選填）、品牌（選填）、照片位置、入庫時間、狀態、最後修改時間。
- **穿搭紀錄**：每次「今天穿了什麼」。
- **修改歷史**：每次修改前後的內容、修改者、修改時間、原因，只增不改。
- **個人設定**：所在城市、個人偏好、隱私說明的同意紀錄。

不記錄：價格、購買日期、尺寸。

照片只有在使用者確認「加入」之後才會存進資料夾；每人衣櫃上限 200 件。

## 隱私與資料規則

- 第一次使用，bot 先說明：照片存在跑 bot 的那台電腦、會送給 Claude 分析、管理者看得到檔案、可以隨時刪除全部資料。使用者按「我同意」（或回覆「我同意」）才開始，沒同意就什麼都不存。
- 不是衣服、太模糊的照片，只回覆提示，**什麼都不存**。
- 使用者可以刪除某件衣服的照片、只留文字。
- 使用者可以**刪除自己的全部資料**：永久清除整個個人資料夾（含照片、衣櫃、穿搭紀錄、修改歷史、設定），要兩道確認（按鈕＋打出「確認刪除全部」），無法復原。
- 所有私人資料只放在 `DATA_DIR` 底下，**絕不 commit 或上傳到公開的 GitHub**（照片、Excel、個人設定都不行）。

## 與老師評分流程的相容

評分 Agent 使用 `ready` 和 `/done` 這兩個操作。**StyleMate AI 不可以干擾**：

- 不回應、不反應、不處理這兩個訊息；
- 不定義任何叫 `ready` 或 `done` 的指令；
- bot 自己也不會在頻道裡發出這兩個字當作訊息。

## 限制（每位使用者）

| 項目 | 限制 |
|---|---|
| 上傳照片 | 每分鐘最多 3 張 |
| 排隊中的工作 | 同時最多 3 件 |
| 推薦與口語指令 | 每分鐘最多 5 次 |
| 圖片 | 10 MB 以內，只收 jpg、png、webp、gif |
| 不花額度的指令（衣櫃、統計、查看） | 不限制 |

超過限制時，bot 回一句明確的原因，不處理、不存任何東西。

## 不需要的

- 註冊、登入（身分就是 Discord 帳號）
- 長時間、大規模的雲端服務（這就是一支開著才會動的本機程式）
- 主動提醒（例如每天早上自動推薦）
- 購物連結、價格、商品推薦（只說「建議買哪一類」）
- 裁切衣服、價格／尺寸／購買日期欄位
- 第三方衣櫃或電商整合

## 技術上我知道的

- 用 Python 3.12 + uv
- 照片與文字用 `claude -p` 在我這台電腦上處理
- Discord 用 Gateway（bot）模式，不需要 ngrok
- 資料存成 Excel（每人一個檔）
- 設定放在 `.env`：`DISCORD_TOKEN`、`CHANNEL_ID`、`CLAUDE_MODEL`、`DATA_DIR`

## 做事的順序

1. 先把 agent 做好，**所有防護都開著**，自己測到正常。
2. 之後（上課時）再把防護全部關掉做對照。
3. 分階段完成：（一）每人分開的衣櫃：上傳辨識、加入、列表、修改、刪除、歷史；（二）穿搭紀錄與統計；（三）推薦穿搭與天氣；（四）自然語言與公開展示模式。
